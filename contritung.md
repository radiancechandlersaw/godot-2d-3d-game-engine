## 🚨 Symptoms of a Broken Godot Setup

Before you add another scene, check whether your Godot project suffers from any of these classic symptoms. Each one points to a specific fix this guide teaches.

| **Symptom** | **What It Really Means** | **Fix This Guide Teaches** |
|-------------|---------------------------|------------------------------|
| 😵 Nodes don't talk | No signals | Signal wiring |
| 🐌 Scene loads slow | Eager load | `preload` / lazy |
| 🧊 Physics broken | Wrong body | RigidBody vs Character |
| 🔥 Export fails | Missing templates | Export templates |
| 📉 2D vs 3D confused | Wrong root | Scene root choice |
| 🔇 No input | Input map | Project settings |

> **💡 Tip:** If nodes don't respond, you're likely missing a signal connection — check the Node dock.

## 🚀 First 5 Minutes — Minimal Working Example

The fastest way to run a scene.

**Step 1 — New Project.** Create a 2D or 3D project.

**Step 2 — Root.** Add a `Node2D` or `Node3D`.

**Step 3 — Child.** Add a `Sprite2D` or `MeshInstance3D`.

**Step 4 — Script.** Attach GDScript.

**Step 5 — Run.** Press F5.

> **💡 Tip:** Always test a scene in isolation with "Play Scene" (F6) before running the full project.
